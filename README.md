# Stories in Structure

Source code for [storiesinstructure.com](https://storiesinstructure.com) — a blog by Agata Migalska exploring structure hidden in the world around us: sensor data modelled as graphs, 3D reconstruction, visual attention, and reasoning over graphs with AI.

Built with [AstroPaper](https://github.com/satnaing/astro-paper) (Astro + TailwindCSS).
